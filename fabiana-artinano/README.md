## Run locally

No build process is required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.

For the best local development experience, use a simple local server such as VS Code Live Server.

## Before publishing

Replace the placeholder content with Fabiana's real information:

- Add Fabiana's professional photo to `images/`.
- Replace the photo placeholder in `index.html`.
- Replace `hello@fabianaartinano.com` with the correct email address.
- Replace the LinkedIn `href="#"` with Fabiana's real LinkedIn URL.
- Replace the sample testimonial with an approved client testimonial.
- Review the coaching descriptions and FAQ.
- Add a favicon if desired.

This project is a static website and can be deployed with GitHub Pages, Netlify, Vercel, or another static hosting provider.
